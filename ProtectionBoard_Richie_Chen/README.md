# ProtectionBoard_Richie_Chen

Blank KiCad 9 project for the SMV 2026-2027 protection board.

Open `ProtectionBoard_Richie_Chen.kicad_pro` in KiCad, then open the schematic or PCB editor.
The schematic and PCB are intentionally empty and ready for design work.

Work on the `ProtectionBoard_Richie_Chen` Git branch. From the repository root,
save and upload future changes with:

```bash
git add -- ProtectionBoard_Richie_Chen
git commit -m "Describe your protection board changes"
git push
```

Commit the project, schematics, PCB, and any required local libraries together.
Local preferences, lock files, caches, and automatic backups are ignored.
